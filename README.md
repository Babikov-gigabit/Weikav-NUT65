# NUT65 Control — локальная утилита для Weikav NUT65

Настройка подсветки и макросов клавиатуры **Weikav NUT65** без браузера и без интернета.
Работает по протоколу VIA (тому же, что usevia.app), поэтому ничего не перепрошивает и
ничего не ломает: всё, что вы меняете, можно вернуть через VIA или фирменный веб-драйвер.

## Что умеет

- **Подсветка:** 46 эффектов, яркость, скорость, цвет (палитра + готовые цвета). Изменения
  видно сразу; кнопка «Сохранить в память клавиатуры» оставляет их после отключения.
- **Макросы:** 16 ячеек (M0–M15, точное число берётся из клавиатуры). Можно написать текст
  вручную или нажать «● Записать нажатия» и просто понажимать клавиши. Есть паузы и сочетания.
- **Клавиши:** назначить макрос (или любую клавишу, Fn-слой, функцию NUT65 — BT1, RL_MOD и т.д.)
  на любую клавишу любого слоя.
- **Профили:** экспорт/импорт подсветки и макросов в файл `.json`.
- **Демо-режим:** кнопка «Демо» — попробовать интерфейс без клавиатуры.

## Запуск на Windows

1. Установите Python 3.10+ с [python.org](https://www.python.org/downloads/) (галочка «Add to PATH»).
2. Подключите NUT65 **кабелем USB** и переключите её в проводной режим.
   По Bluetooth и 2.4G настройка не работает — так устроена сама клавиатура.
3. Дважды щёлкните `run.bat`. При первом запуске он сам поставит модуль `hidapi`.
4. Нажмите «Подключить».

Хотите один `.exe` без Python? Запустите `build_exe.bat` — файл появится в `dist\NUT65-Control.exe`.

## macOS / Linux

```
pip install -r requirements.txt
python3 run.py
```
На Linux нужен доступ к устройству: скопируйте `99-nut65.rules` в `/etc/udev/rules.d/`
и выполните `sudo udevadm control --reload && sudo udevadm trigger`, затем переподключите кабель.
Если нет модуля tkinter: `sudo apt install python3-tk`.

## Как писать макросы

| Запись | Что делает |
|---|---|
| `Hello world` | печатает текст (только латиница и ASCII-символы) |
| `{KC_ENT}` | нажимает Enter |
| `{KC_LCTL,KC_C}` | сочетание Ctrl+C |
| `{KC_LGUI,KC_R}{300}notepad{KC_ENT}` | Win+R, пауза 300 мс, «notepad», Enter |
| `{+KC_LSFT}abc{-KC_LSFT}` | зажать Shift, напечатать, отпустить |
| `{{` | символ `{` |

Русский текст макросом напечатать нельзя: клавиатура отправляет коды клавиш, а не буквы.
Обходной путь — переключить раскладку в макросе (например `{KC_LALT,KC_LSFT}`) и печатать
латинскими клавишами, на которых стоят нужные русские буквы (`ghbdtn` = «привет»).

После правки нажмите «Записать в клавиатуру», затем во вкладке «Клавиши» щёлкните по нужной
клавише и выберите макрос.

## Что не умеет

- Боковая световая полоса и музыкальный режим не управляются через VIA — их переключают
  Fn-сочетаниями на клавиатуре или кодами `RL_MOD`, `RL_VAI`, `RL_VAD`, `MUS_CUT`, которые можно
  повесить на клавишу во вкладке «Клавиши».
- Прошивку не обновляет (Weikav сами советуют не обновлять без необходимости).

## Устройство проекта

- `nut65/via.py` — протокол VIA (raw HID, usage page 0xFF60, пакеты по 32 байта)
- `nut65/macro.py` — перевод макросов «текст ↔ байты в памяти клавиатуры»
- `nut65/keycodes.py` — коды клавиш QMK
- `nut65/emulator.py` — эмулятор клавиатуры для демо и тестов
- `nut65/app.py` — интерфейс (tkinter)
- `tests/` — тесты: `python -m unittest tests.test_core`

Данные о клавиатуре взяты из официального VIA JSON для NUT65 (VID `0x342D`, PID `0xE51A`).
